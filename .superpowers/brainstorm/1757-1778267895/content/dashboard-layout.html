Dashboard layout — which feels right?

Both use the same charcoal sidebar and warm-gray background. The difference is sidebar width and content density.

A — Compact icon sidebar Minimal

Icon-only sidebar saves horizontal space. More room for content. Navigation labels appear as tooltips on hover. Works best on smaller screens and feels modern/focused.

B — Labeled sidebar Scannable

Labeled sidebar shows nav names always visible. Easier to orient new users. Slightly less content width. Works great for SaaS tools owners use daily. Classic and clear.
